WhiteboxTools Integration Example
=================================

This example demonstrates how to use WhiteboxTools through the Py-GeoSpatial interface.

The example script is available at: ``examples/whitebox_integration.py``

Key concepts demonstrated:

* Basic WhiteboxTools usage
* Terrain analysis operations
* Hydrological analysis operations
* LiDAR processing operations
* GPU acceleration with WhiteboxTools
* WhiteboxTools configuration options

Run the example::

    python examples/whitebox_integration.py

Note: Most operations require actual data files and WhiteboxTools installation.
